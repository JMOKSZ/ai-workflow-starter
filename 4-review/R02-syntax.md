# R02 — 语法审（Round 2）

> **用途**: 审查代码是否能编译/运行、有没有低级错误。  
> **前置条件**: Round 1 的问题已全部修复。  
> **执行**: 由**另一个Agent**执行（和Round 1分开）。

---

## 审查清单

### 1. 编译/类型
- [ ] 代码编译通过（无类型错误）
- [ ] 所有 import/require 正确
- [ ] 没有未使用的变量/imports

### 2. Lint
- [ ] 符合 coding style（命名、缩进、空行）
- [ ] 没有明显的反模式
- [ ] 代码风格和项目现有代码一致

### 3. 测试
- [ ] 新代码有对应的测试
- [ ] 已有测试全部通过
- [ ] 测试覆盖了边界条件

### 4. 运行时
- [ ] 没有明显的 NPE / NullReference / TypeError 风险
- [ ] 异步代码有 await / then 处理
- [ ] 资源有正确释放（文件句柄、数据库连接）

---

```
## Round 2 审查结果

### ✅ 通过的
- {{条目}}

### ❌ 需要修的

### ✅ 最终结论
```
