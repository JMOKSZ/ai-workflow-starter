# Harness — 受控流水线

> **用途**: 定义一个标准化的开发任务执行流程，让AI按步骤走，不自由发挥。  
> **工作方式**: 每次执行 `3-skills/S03-code-gen.md` 时携带本文件作为上下文。

---

## 流水线定义

```
[需求文档确认] ──→ [技术文档确认] ──→ [Harness启动]
                                            │
                                    ┌───────┴────────┐
                                    │  任务拆解        │
                                    │  (1个大任务→     │
                                    │   N个小任务)     │
                                    └───────┬────────┘
                                            │
                                    ┌───────┴────────┐
                                    │  逐个执行        │
                                    │  每个子任务：     │
                                    │  1. 读上下文     │
                                    │  2. 写代码       │
                                    │  3. 自查        │
                                    │  4. 更新文档     │
                                    │  5. 验证        │
                                    └───────┬────────┘
                                            │
                                    ┌───────┴────────┐
                                    │  双重 Review     │
                                    │  R1: 逻辑审      │
                                    │  R2: 语法审      │
                                    └───────┬────────┘
                                            │
                                    ┌───────┴────────┐
                                    │  测试 + 回归    │
                                    │  → PR          │
                                    └────────────────┘
```

## 入口规则

当被调用来生成代码时，必须：

1. **先确认前置条件满足**：
   - 需求文档存在且已标注"已确认" ✅
   - 技术文档存在且已标注"已确认" ✅
   - 已读 ARCHITECTURE.md + 2-rules/

2. **严格按照 S03-code-gen.md 的分步流程执行**

3. **输出**：
   - 变更文件清单（增/改/删）
   - 变更内容摘要
   - 需人工注意的点
